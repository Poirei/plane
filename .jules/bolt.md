## 2026-10-01 - Do not use `useMemo` for MobX observables\n**Learning:** Using `useMemo` inside an `observer` component to cache values derived from MobX observables is an anti-pattern. If the factory function skips execution, MobX won't track the observables, breaking reactivity.\n**Action:** Avoid caching observable derivations with React's `useMemo`. Instead, use MobX's `computed` properties or allow the `observer` to run the derivations directly during the render cycle.
